Gemini confidential OAuth, read-only account snapshots and SDK token refresh are implemented but untested with a real account. Refresh/access token bundles are AES-GCM encrypted in Postgres; callback state is short-lived, browser-bound and one-use. Production app review remains blocked.

Gemini public-data recovery (2026-11-18): reproduced HTTP 400 `NoDataFound` for all chart ranges on the new UConn–Arizona contract. Only that explicit response becomes empty history; coarse intervals still try minute candles, while other 4xx, outages and malformed responses remain errors. Existing Notre Dame candles and a complete live catalog read passed through the corrected adapter. SDK response-size failures now shrink the page at the same offset down to one event, retaining the response-size cap and rejecting incomplete scans. Snapshot retries back off from 30 seconds to five minutes during a sustained upstream outage, retain the saved data/timestamp and reset after success. Regression tests exercise the SDK's real bounded response reader and empty-history error type; public-read logs include safe SDK status/reason/operation fields without raw bodies or credentials.

All mainnet money-moving actions remain disabled even if an environment flag is accidentally enabled. Live release requires replacing the blocked adapter with verified implementation and tests, exact provider permissions, and explicit per-action user approvals. No bridge, trade, withdrawal, purchase, shipping or full bounty completion is claimed.
