# Hackathon demonstration

The prototype is a real public-data application with simulated trading, not a completed real-money redemption service.

1. Open Markets. Verify public Gemini catalog provenance. Select Crypto/Sports or search to query the actual provider, then open an event. Nested child market contracts remain selectable.
2. On the market page, watch real order-book depth and session observations. Switch YES/NO, adjust the stake, and observe quantity/payout changes. Unknown live fees stay unverified; stale books pause estimates. No live trade button is enabled.
3. Open Practice from navigation. This selects the invented `SIMULATED-HOME-YES` book. Review and confirm a simulated order; Portfolio stores it on this device. It is never a real Gemini position or a real settlement.
4. Open Rewards, inspect actual front/back slab images, select listings, and plan a multi-card cart. Budget is a planning amount, not a verified wallet balance. Ask is not FMV. Card Hedge FMV/comps appear only with server credentials and licensed public-display flag, from persistent 18-hour certificate-matched cache.
5. Wallet shows separate Gemini and Solana areas. When configured, official Privy Google/email login provisions an embedded Solana wallet; an external wallet can connect and prove ownership. No second wallet connector stack or local key storage.
6. Use the read-only Solana transaction inspector on devnet. Recorded verification signature and limitations are in INTEGRATION_VERIFICATION.md. The public faucet returned HTTP 410, so full signed devnet marketplace purchase remains unverified.
7. Explain the blocked funding route: available USD, conversion permission/fill, account-specific USDC networks, approved owned destination/hold, exact fees and explicit approvals. Relay is only a conditional owned-EVM-wallet fallback, never a temporary CEX deposit shortcut. No successful bridge/withdrawal is claimed.
8. For the Solana bounty, configure a real QuickNode Stream and capture signed delivery plus independent owner reconciliation using QUICKNODE_STREAM.md. Current code is not proof of a configured Stream.

Screenshot evidence from the design task is stored locally under ignored `artifacts/`: Gemini and Polymarket reference captures plus the actual application capture. These are design evidence, not provider license grants.
